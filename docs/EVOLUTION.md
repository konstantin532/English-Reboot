# Эволюция English Reboot

Журнал итераций саморазвития (скилл `english-reboot-evolve`). Одна итерация — одно улучшение,
отдельная ветка `feature/…` и pull request; в `main` сливает только автор.

Цель продукта: русскоязычный ученик A2 за 90 дней по 15 минут в день начинает говорить на
американском разговорном английском и понимать живую речь — фильмы, сериалы, песни.
Главная метрика — сколько фраз ученик сказал вслух сегодня.

**Схема сложности заданий** (решение автора): методика в духе LinguaLeo постепенно уступает
заданиям на произношение в духе ELSA Speak. Только принцип — без их контента, оформления и названий.

| Подуровень | LinguaLeo / ELSA | Задания |
|---|---|---|
| A1 | 100 / 0 | выбрать значение |
| A1+ | 100 / 0 | + собери из букв, напиши на слух, перевод с русского ✅ |
| A2 | 80 / 20 | + «скажи слово вслух» (распознавание речи), пары звуков на слух |
| A2+ | 70 / 30 | + ударение, фраза вслух по образцу |
| B1 | 40 / 60 | + слитная речь и интонация |
| B1+ | 25 / 75 | + длинные реплики вслух, паспорт ловушек решает, что тренировать |
| B2–B2+ | 0 / 100 | произношение и восприятие на слух: сарказм интонацией, быстрая речь, акценты |

Ограничение: распознавание речи в браузере проверяет слова, а не отдельные звуки (как ELSA), и работает
онлайн в Chrome; без него — запись и самооценка. Оценка по звукам — только по решению автора (тяжёлая модель).

## Разведка 2026-10-06

Короткая (поиск дал мало нового за неделю; продукты стоит перепроверять в следующих итерациях).

- **Language Reactor** ([сайт](https://languagereactor.com)) — двойные субтитры поверх YouTube/Netflix,
  пауза после каждой реплики, словарь кликом. Сильная сторона — живой материал. У нас: всё офлайн,
  американская IPA и русская транскрипция с ударением. Принцип на заметку — «автопауза после фразы»
  для будущего «Уха для кино» (на своих фразах и TTS).
- **Lingopie** ([обзор от Lingopie](https://lingopie.com/blog/language-reactor-review/)) — сериалы
  с интерактивными субтитрами и карточками из просмотренного. Чего нет у нас: связь просмотра
  с повторением. Идея «Мой текст» закрывает это локально и без чужих текстов в репозитории.
- **Trancy** ([сравнение](https://air.trancy.org/blog/trancy-vs-language-reactor-which-is-better-in-2026-3179d225200580118e5adf26153345a1))
  — конкурент Language Reactor с ИИ-разбором фраз из видео.
- **ELSA Speak** ([сравнение с Speechling](https://www.talkdrill.com/blog/compare/elsa-speak-vs-speechling/))
  — оценка произношения по звукам. У нас честнее: похвала только после настоящей проверки.
- **YouGlish** ([обзор JALT](https://jalt-publications.org/articles/29732-listening-practice-youglish-com))
  — слово в реальных видео. Можно давать ссылку-поиск как онлайн-бонус к карточке (не встраивая материалы).
- **Minimal pairs-тренажёры** (например, [Soundwise English](https://appshunter.io/ios/app/soundwise-english/id6753882308))
  — тот же формат, что наш тренажёр на слух; у нас он уже есть, эта итерация сделала его устойчивее.
