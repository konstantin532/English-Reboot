# Product

<!-- impeccable:product-schema 1 -->

## Platform

web

## Users

- **Primary: the student.** A Russian-speaking adult who studies English alone, about 15 minutes a day, at A1–B2 (the course is built around A2). They open the app on a phone and on a computer about equally often. The job: within ~90 days start saying everyday American English phrases aloud without a pause and recognize them in live speech (films, series, songs).
- **Secondary: people evaluating the author.** The project is part of a QA engineer's portfolio, so recruiters and engineers open it once to judge craft. Confirmed by the author (2026-10-09): both audiences matter equally — daily comfort for the student and a strong first impression on a first visit.

## Product Purpose

An offline-first web app (PWA) for learning conversational American English. Success is measured by one number: how many phrases the student said aloud today. Everything else (cards, tests, streaks) serves getting the student to speak.

## Positioning

- Russian-letter transcription under every word of every example, showing how it sounds in the US, with stress (car → кар, water → у́отэр); American IPA for 100% of words (CMU dictionary), including homographs resolved by context.
- Markup layers on example sentences: parts of speech by colour, silent letters, unexpected sounds, stressed syllable, connected speech (want to → wanna). Tap any word to hear it.
- FSRS-4.5 spaced repetition (as in Anki) with an honest "memory today" metric.
- Works fully offline in the browser, no account, no server: IndexedDB storage, local backups, export to Anki/Quizlet, QR sync.

## Operating Context

- Daily ritual: open «Сегодня» (Today) → one lesson of up to ~15 minutes: new phrases (listen, repeat aloud, climb the "ladder"), words, a scene with characters, improvisation.
- Library sections: Words, Grammar, Phrasal verbs, Collocations, Idioms, Conversational phrases, Slang, Minimal pairs, Reading, My deck. Practice: Trainer (SRS review, dictation, shadowing, phrase ladder, scenes, improvisation), IELTS (Academic writing/speaking/reading). Me: Progress, Settings.
- Search across all content with Ctrl+K; a personal word bank; light, dark and AMOLED themes.
- First run: a placement test (20 questions) or manual level choice, then a daily goal.

## Capabilities and Constraints

- Vanilla HTML/CSS/JS, no build step, no frameworks, no app dependencies; modules are IIFEs exposing globals; one `index.html` entry; deployed to GitHub Pages.
- UI is rendered as HTML strings from many JS modules (`js/*_ui.js`, `js/app_*.js`); class names and element ids are used by E2E tests (Playwright) and must keep working.
- Offline: any new file must be listed in `sw.js` ASSETS and `CACHE_VERSION` must be bumped on every app change (enforced by `scripts/er-guard.mjs` in CI). Fonts are served locally from `fonts/` — no hosted font CSS.
- The part-of-speech colour palette lives in a marked block `POS-PALETTE:BEGIN/END` in `css/style.css`; `tests/palette.test.js` requires every pair of POS colours to differ by ΔE2000 ≥ 20 in light and dark themes, and dashed grey for function words, no red for stress.
- Every section has its own colour code and letter glyph (defined in `js/app.js` `TABS`).
- Interface language: Russian. Content: American English only (no British spelling or IPA).
- Speech recognition only works online in Chrome; elsewhere the app falls back to recording and self-rating.

## Brand Commitments

- Name: **English Reboot**.
- **The incumbent look stays** (author, 2026-10-09): keep the current visual identity (light Apple-like interface, section colour coding with letter icons, system-font stack); improve design and layout within it, no new visual world.
- **Gamification stays as a visible accent** (author, 2026-10-09): XP, streak, achievements, combo, daily challenges, league remain noticeable, not hidden.
- Voice: short, direct, warm Russian; honest promises (PEDAGOGY rule 7) — never more than ~22 hours in 90 days can deliver. Praise lines live only in `js/coach.js`.

## Evidence on Hand

- Real content: 3,252 cards — 748 words A1–A2 in 19 topics + 78 A2 verbs, 67 grammar topics, 297 phrasal verbs, 207 collocations, 108 idioms, 1,645 conversational phrases (1,503 American spoken), 165 improvisation situations and 15 "Yes, and…" stories, 110 slang cards, 47 minimal pairs, 23 reading texts.
- Tests: Vitest unit suites and Playwright E2E scenarios, CI on GitHub Actions; README screenshots generated by `scripts/screenshots.mjs` into `docs/screenshots/`.
- No user counts, testimonials, ratings, or press exist — never invent them.

## Product Principles

1. Speaking aloud is the headline number; the interface should always point the student toward saying the next phrase.
2. Today first: the daily lesson is the front door; the library is for looking things up.
3. The markup on a sentence is the product's signature — it must be legible, calm and tappable on any screen.
4. Offline and private by default: nothing depends on a network or an account.
5. Honest progress: show real counts and real memory, never inflated claims.

## Accessibility & Inclusion

- Keyboard navigation (skip link, Ctrl+K, focus rings), aria labels and dialog roles, light/dark/AMOLED themes, `prefers-reduced-motion` respected.
- Part-of-speech colours must stay distinguishable for the eye (ΔE2000 ≥ 20) and are paired with line style (solid / double / dashed), so meaning never rests on hue alone.
