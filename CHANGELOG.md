### Added

- **Инструменты скилла развития (dev, ученику не видны).** Механику итерации делают скрипты, модель
  получает короткие сводки вместо логов: `scripts/er-health.mjs` (юнит + E2E + аудит против «Эталона»),
  `er-brief.mjs` (осмотр проекта), `er-guard.mjs` (сторож правил по диффу), `er-shots.sh` (скриншоты
  до/после с попиксельным сравнением), `er-ci.mjs` (CI через REST), `er-test-env.sh` и `scripts/er-shim/`
  (тесты в облачной сессии без реестра npm). Разбор отчётов и правила сторожа — `tests/er_tools.test.js`.
  Одна точка входа `scripts/er.mjs`: тихие `er test` / `er e2e`, фоновые `er start` / `er finish` / `er wait`;
  `er-review.mjs` — ревизору кода дифф без сгенерированных данных, педагогу карточки текстом с тестами,
  слова с изменившейся IPA и выборку разметки слов (часть речи, ударный слог, немые буквы) новых карточек,
  а при правке движка разметки — и по всему курсу; сторож требует `*_VERSION` по изменённым карточкам;
  `er-brief` — следующие номера карточек.

- **Честная мотивация** (`js/coach.js`, `js/pacers.js`):

    с образцом по словам — верно / услышано другое / не расслышано, оценка 0–100,

    в текущем Chromium роняет вкладку.

- **Импровизация** (`js/improv.js`, `js/improv_us.js`, `js/improv_ui.js`):

  - ступень 8 лестницы стала полноценной импровизацией со своей фразой как условием.

### Changed

- Тесты к фразам «Первый месяц»: вместо «Где это говорят?» — слово внутри фразы (gonna / wanna /
  gotta по смыслу); неверные ответы в диалоге — из служебных тем; к пропуску — перевод фразы.
- Тесты к словам: группы синонимов объединяются (fine больше не получает great в варианты).
- `scripts/screenshots.mjs` ждёт конца загрузки контента перед пропуском онбординга.

- **Омографы в транскрипции**: CMU первым даёт один вариант, и в 35 примерах курса стояло не то
  произношение — «I live in Brooklyn» /laɪv/, «Close the door» /kloʊs/, «I read before bed» /rɛd/,
  «The wind is cold» /waɪnd/. Теперь `lex_us.js` выбирает вариант по соседним словам (live, close, read,
  use, wind, lead); тест на реальных примерах в `tests/content_audit.test.js`.
- **Тесты к словам**: синонимы и близкие слова (little/small, learn/study, house/home…) не попадают
  в неверные варианты; к дням недели неверные варианты — тоже дни (иначе ответ выдаёт заглавная буква).
- Роли героев в импровизациях A1 сверены со сценами: Мэгги — соседка по квартире (не официантка),
  мисс Гарсия — сотрудница банка, мистер Окафор — арендодатель (не начальник; задачу объясняет Прия).

- **«Сегодня» для ученика A1** начинается с темы «Первая неделя», хотя её фразы дописаны в конец курса.
  Уровень берётся из настроек; для других уровней и без уровня порядок курса прежний.
- **Тесты к американским фразам**: неверные варианты не берутся из похожих тем (иначе в вопросе два
  верных ответа); у фраз с подуровнем — из того же или соседнего уровня; во «вставь фразу» регистр
  вариантов совпадает с ответом (строчная буква в середине предложения больше не подсказывает).
- **Уровень на карточке** показывает подуровень, если он есть (A1+, B2+…).
- **База IndexedDB версии 2**: при обновлении создаётся только новое хранилище `words`, прогресс и
  настройки не трогаются (E2E `tests/e2e/words.spec.js`). `sw.js`: `CACHE_VERSION` → er-v32.
- **Аудит контента**: «Call 911» больше не считается дублем слова «call» (цифры значимы), омонимы из
  раздела «Слова» с другим переводом (like «нравиться» и филлер like «типа») — тоже.
- **`docs/EVOLUTION.md`** — журнал итераций развития: бэклог, решения, разведка конкурентов.
- **`app.js` разделён на ядро и пять модулей** (поведение не изменилось): `app_ui.js`, `app_library.js`,
  `app_session.js`, `app_progress.js`, `app_settings.js`. `app.js` — 781 строка вместо 2331.
  Код перенесён без правки логики; модули получают общее состояние и функции ядра через контекст
  `core` (геттеры, для переприсваиваемых переменных — сеттеры). Проверка: все юнит- и E2E-тесты,
  попиксельное сравнение 33 снимков экранов (11 экранов × 3 темы) с версией до разделения.
- Тест `tests/app_modules.test.js` следит за связями ядра и модулей; E2E `tests/e2e/core.spec.js` —
  за действиями, которые меняют состояние ядра из модуля (сброс прогресса, тренажёр на слух,
  окно слова в чтении, тема, Escape).
- **Контент стал американским** (этап 7, по отчёту аудита):
  - IPA: 1136 записей в разборе примеров переведены с британской на американскую — по словарю
    CMU (тот же перевод, что у `lex_us.js`), служебные слова — слабые формы (for /fɚ/), /ɛ/ вместо /e/;
    у сленга, пар звуков и звуков — тоже. Русская подсказка пересчитывается сама;
  - написание: color, neighbor, apologize, canceled, gray, center, favorite, traveling…;
  - слова: flat → apartment, lift → elevator / ride, petrol → gas, mum → mom, autumn → fall,
    queue → line, CV → resume, car park → parking lot, rubbish → trash и др. (37 мест);
  - сленг: британские innit, cuppa, ta, loadsa и несуществующий howzza заменены на didja, ya,
    'kay, hadda, c'mere;
  - minimal pairs: caught / cot (у многих американцев звучат одинаково) → hot / hat; bath / bass —
    про /θ/–/s/; объяснения под американскую запись (/i/, /ɛ/, /ɝ/, /ɑr/, /oʊ/);
  - книжное: «Shall I/we…?» в примерах → «Should I…?», «Want to…?»; в «Have got» — как в США
    говорят в вопросах и отрицаниях;
  - дубли одной фразы в одном разделе объединены (`js/content_migrate.js`): прогресс переходит на
    оставшуюся карточку; у карточек, ставших другой фразой, прогресс сброшен. Версии контента
    подняты — правки дойдут до тех, кто уже занимается.
- Защитные тесты: британская IPA, написание, слова и сленг не должны вернуться.
- Формулировки без рода: «Сказано вслух: 3 фразы», «Открыто ступеней: 3».

- **«Сегодня» — урок за 15 минут** (`js/today.js`, `js/today_ui.js`) — новый стартовый экран
  с одной кнопкой «Начать». Внутри урока:
  - разминка — до 5 фраз, которые пора повторить по FSRS (сначала забытые, затем фразы
    со слабыми ловушками акцента);
  - 3 новые фразы одной темы: знакомство «послушай и повтори вслух» с записью голоса —
    первая фраза вслух в первые минуты — и затем 3 круга по лестнице;
  - итог дня: «сказано вслух: N фраз, открыто ступеней: M», минуты и серия.
  Урок можно прервать и продолжить в тот же день, в том числе после перезагрузки
  (`settings.today_lesson`). Блоки сцены и импровизации появятся вместе с этапами 3 и 4.
- Разделы собраны в группу «Библиотека»; после онбординга ученик сразу попадает на «Сегодня».
- Открытые за день ступени считаются в `study_log.stepsUp`.

- **Лестница фраз — 8 ступеней от «узнай» до «скажи сам»** (`js/ladder.js`, `js/ladder_ui.js`):
  узнай на слух → выбери уместное → собери из слов → впиши по памяти → смени тон →
  скажи вслух → ответь своими словами → импровизация. Ступень открывается при ≥80%
  верных из последних 5 попыток (минимум 3), ошибка — шаг назад. Какие фразы
  повторять, по-прежнему решает FSRS. Вход: «Тренажёр → Лестница фраз» и кнопка
  «Тренировать» на карточке американской фразы. Дистракторы — из той же темы;
  если ученик считает, что его вариант тоже подходит, попытка не засчитывается,
  а пара уходит в список для ручной проверки (`settings.ladder_disputes`).
  Ступени 6–8 пока работают с самооценкой (запись голоса + образцы).
- **Варианты тона для 50 фраз** (`js/tone_us.js`): вежливее / нейтрально / как другу.
  У остальных фраз ступень «Смени тон» пропускается.
- **Ловушки русского акцента** (`js/traps_us.js`, `js/traps_ui.js`): 10 ловушек — [æ] (bad ≠ bed),
  придыхание [p t k], th, американское r, w ≠ «в», звонкие на конце, редукция (gonna, wanna),
  flap t (water → «уо́дэр»), ударение, тёмное l. У каждой — объяснение «по-русски так,
  по-английски так» и 12 минимальных пар, написанных вручную.
  - На карточке американской фразы и в лестнице слова с ловушками подчёркнуты; клик —
    объяснение, слова фразы с озвучкой и пара на слух (bad → bed).
  - Мини-тренажёр «5 пар на слух» для каждой ловушки.
  - **Паспорт акцента** на вкладке «Прогресс»: какие ловушки побеждены (≥80% из последних
    10 попыток, минимум 5), какие в работе. Считаются тренажёр пар и ступени лестницы
    «Узнай на слух» и «Скажи вслух» (`settings.accent_passport`, попадает в экспорт и автобэкап).
  - Лестница первыми берёт фразы со слабыми ловушками ученика — из тех, что пора повторить
    по FSRS, и из новых. Интервалы FSRS не меняются.
  - Разметка ищет [æ], th, w, звонкие на конце и ударение по IPA, а r и flap t — по написанию:
    в данных встречается британский IPA (water /ˈwɔːtə/), его исправление — в этапе 7.
- **Счётчик «фраз вслух»**: запись от 1 секунды в лестнице засчитывается за день
  (`study_log.spoken`), итог показывается после урока.

  технологии, small talk. У каждой диалог, пример и 5 тестов.
  Разговорные фразы: 106 → 1149, всего карточек: 1878.
- **FSRS‑4.5** вместо фиксированной лестницы 1→3→7→14→30→90: стабильность и
  сложность каждой карточки, интервал под 90% вероятности вспомнить (как в Anki).
  Быстрый «Знаю» (< 3 с) считается оценкой Easy. Метрика «Память сегодня» на «Прогрессе».
- **Русская транскрипция** под каждым словом — как звучит в США, с ударением;
  нажатие на слово озвучивает его. Слой «Русская транскрипция» в настройках.
- **Американская IPA для всех слов** (`js/lex_us.js`, CMU Pronouncing Dictionary):
  было около 45% слов без транскрипции, стало 0%.
- **Резервная озвучка:** голос системы → живая американская запись слова
  (Wiktionary) → онлайн-синтез фразы. Раздел «Настройки → Звук»: диагностика,
  выбор голоса, проверка, инструкция по установке английского голоса.
- **Новый интерфейс «линии метро»:** у каждого раздела свой цвет и значок, меню —
  в левой колонке по группам, чёрная шапка-указатель, шрифт Golos Text, новый онбординг.
- Тесты: 44 юнит-теста (FSRS, транскрипция, озвучка, целостность контента,
  IELTS) и 10 E2E-сценариев, включая запуск без сети.

### Fixed

- **Разметка слов в примерах — у всех карточек, включая новые.** У слов пакетов A1 и A1+ не было цвета части
  речи и немых букв (0% слов), ударение — не у всех многосложных. Теперь `js/word_marks.js` размечает курс
  перед записью карточек в базу: часть речи (словарь `js/pos_us.js` + поле pos карточки + соседние слова;
  98% совпадений с ручной разметкой грамматики), ударный слог по американской IPA (ho·tel, ba·nan·a, lis·ten,
  cor·rect) и немые буквы по ней же (know, walk, two, listen, night, Wednesday, liked). Исправлены ошибки старой
  ручной разметки: немыми были помечены p в please, t в two, k в walk, o в work. Конечная «немая e» (make, here)
  не помечается — правило A1.
- **Глагол виден там, где он глагол.** Словари LEX файлов контента давали слову одну часть речи на весь курс:
  have, had, is, was — всегда «вспомогательный» (серый), to — всегда частица, work — всегда глагол. Теперь это
  подсказка, а решает контекст: «I **have** an idea», «We **had** a long chat» — глагол (красный), «I look forward
  **to** your reply» — предлог, «this kind of **work**» — существительное. Пословная ручная разметка грамматики
  не меняется. Изменилась часть речи у 884 слов в примерах.
- **Ударный слог у слов с ручной IPA без знака ударения** (today, family, money, prediction, advice — 629 слов):
  слог берётся из словаря `lex_us.js`, иначе по номеру слога из лексикона.
- **Minimal Pairs**: в 41 карточке пример показывался со служебными скобками — «The {ship} is in the harbor.»
- IPA с неверным ударением: engineer /ˌɛndʒəˈnɪr/, yourself /jɔrˈsɛlf/, sometimes /ˈsʌmtaɪmz/; британское
  flatmate → roommate.

- Опечатка в счётчике вопросов карточки: «Ответлено» → «Отвечено».

- **Тренажёр на слух (Minimal Pairs)**: после неверного ответа слово повторяется через 0,6 с —
  если за это время уйти с вкладки, в консоли была ошибка TypeError, а если открыть пару заново —
  звучало слово прошлого раунда. Теперь повтор звучит только для текущего раунда. E2E-тест
  `tests/e2e/core.spec.js` проверяет это без ожиданий-обходов.
- **Сброс прогресса во время загрузки раздела**: если нажать «Сбросить прогресс», пока раздел
  загружался, карточки могли снова показать старый статус («выучено»). Теперь загрузка, начатая
  до сброса, в кэш не попадает и база читается заново (`dropCardCaches()` в `js/app.js`).
  E2E-тест в `tests/e2e/core.spec.js`.
- Сленг: строка `SLANG_CARDS[61] = …` промахивалась на один индекс — дубль «lotta» затирал
  карточку «lotsa», она снова в колоде.
- Запоздалое «Сегодня» после онбординга больше не выдёргивает ученика из раздела,
  в который он уже перешёл.
- Фоновая догрузка PRO-контента больше не перерисовывает вкладку поверх открытого урока,
  сцены или лестницы.
- Запоздавший рендер стартового экрана после онбординга больше не затирает открытое
  упражнение (`ER.claimContent`).

- **Сцены: история «Переезд в Нью-Йорк»** (`js/scenes.js`, `js/scenes_us.js`, `js/scenes_ui.js`).
  Герои — соседка Мэгги, коллега Тони и арендодатель мистер Окафор. Партия 1 — 4 эпизода:
  аэропорт JFK, такси до Бруклина, ключи от квартиры, кофейня за углом.
  - Выбор с последствиями: естественно / слишком официально / грубовато. Персонаж
    реагирует по-разному, тренер объясняет разницу, грубый ответ уводит в отдельную ветку.
  - Открытые реплики своими словами с честной проверкой офлайн по «смыслам»: ключевые
    фразы с допуском опечаток и сокращений, отрицания учитываются («not sure» ≠ «sure»).
    Смысл найден — засчитано и показаны варианты носителя. Не найден или ответ голосом —
    образцы и самооценка, без похвал за непроверенное.
  - «Разобрать с ИИ» копирует ответ с готовым промптом в буфер обмена.
  - Сцены в «Тренажёре» (открываются по порядку) и в уроке «Сегодня» после новых фраз.
    Прогресс — `settings.scenes`.
- **Лестница, ступени 7–8**: ответ своими словами засчитывается автоматически, если в нём
  есть фраза или её вариант тона; иначе — образцы и самооценка.
- **Фразы не озвучивались при запуске через .bat** (с диска — озвучивались):
  онлайн-синтез отклонял запросы с Referer `http://localhost`. Добавлен `no-referrer`.
- `.bat` открывал браузер раньше, чем запускался сервер; `.vbs` никогда не замечал
  отсутствие Python и показывал кракозябры вместо русского текста.
- **Не было звука** без английского голоса в системе (типично для русской Windows).
- **Офлайн-режим ломал стили:** CSS импортировал open-props с unpkg.com, шрифты

- Переменная `--strip-h` не была определена — левая колонка позиционировалась неверно.
