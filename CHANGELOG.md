## [Unreleased]

### Added

- **Русская транскрипция** под каждым словом примеров — как звучит в США
  (car → *кар*, water → *у́отэр*), с ударением. Отдельный слой в настройках.
- **Озвучка по нажатию на любое слово** в примере.
- **40 фраз американской разговорной речи** (тег «США»): живые, но без грубостей.
  Разговорные фразы: 106 → 146, всего карточек: 875.
- **Американская IPA для всех слов** (`js/lex_us.js`, CMU Pronouncing Dictionary):
  раньше без транскрипции было около 45% слов в примерах, теперь 0%.
- Анимации кнопок: подъём при наведении, «пружина» при нажатии, волна, блик.

### Changed

- Ударный слог выделяется цветом, немые буквы — тусклые под цвет фона.

### Fixed

- Пункты меню в шапке обрезались.

## [1.0.0] - 2026-10-04

Первый стабильный релиз.

### Added

- **Контент: 835 карточек уровней A1–B2**, загружаются в IndexedDB при первом запуске:
  - грамматика — 67 тем (55 базовых + 12 PRO уровня B2), у каждой есть тест;
  - фразовые глаголы — 207 (158 + 49 PRO);
  - коллокации — 207 (157 + 50 PRO);
  - идиомы — 108;
  - разговорные фразы — 106;
  - сленг — 70;
  - minimal pairs — 47 (40 пар + 7 звуков);
  - тексты для чтения — 23 (17 + 6 PRO) с вопросами.
- **SRS-движок**: интервалы 1 → 3 → 7 → 14 → 30 → 90 дней, ease-фактор,
  учёт времени ответа, lapse-режим для забытых карточек, fuzzing интервалов,
  заморозка серии, прогноз освоения уровня, heatmap по разделам.
- **Онбординг**: входной тест из 20 вопросов для определения уровня или ручной выбор.
- **Тренажёры**: диктант, shadowing с караоке-подсветкой и записью голоса (MediaRecorder),
  карточки с разметкой (IPA, части речи, немые буквы, ударения, connected speech).
- **IELTS-подготовка** (Academic): Writing Task 1/2 с таймером, счётчиком слов,
  автоанализом и самооценкой по 4 критериям band descriptors; Speaking Part 1–3
  с таймером 1 + 2 мин и записью; Reading True/False/Not Given; Academic Word List.
- **Поиск** по всему контенту (Ctrl+K) с фильтрами по уровню и разделу.
- **Гамификация**: XP, комбо, челленджи дня, лига, 12 достижений, календарь занятий.
- **PWA и офлайн**: Service Worker с precache всех файлов приложения, manifest
  с иконками 192/512 и скриншотами для диалога установки.
- **Экспорт/импорт JSON** — полный бэкап прогресса и настроек.
- **QR-синхронизация** настроек и сводки прогресса между устройствами.
- **Экспорт в Anki/Quizlet** и импорт собственных карточек в «Мою колоду».
- **Автобэкапы** в localStorage каждые 7 дней и восстановление при повреждении IndexedDB.
- **Напоминания**: баннер в приложении и локальные уведомления.
- **Обложка проекта** (`docs/cover.svg`) и скриншоты интерфейса в README.

### Changed

- «Изученные» карточки теперь возвращаются на контрольный повтор с длинным
  интервалом, а не исключаются из очереди навсегда.
- Озвучка надёжнее в Chrome/Edge: пауза между `cancel()` и `speak()`, снятие
  синтезатора с паузы, удержание ссылок на фразы, приоритет локальных голосов
  с повтором другим голосом при ошибке синтеза.
- Счётчик «к повторению» корректно учитывает даты в ISO-формате.
- Исправлен дублирующийся вариант ответа в тесте грамматики g031.

### Verified

- **Unit-тесты (Vitest)**: SRS-движок (`tests/srs.test.js`) и анализ эссе IELTS
  (`tests/ielts.test.js`).
- **E2E smoke-тесты (Playwright)**: загрузка без ошибок консоли, прохождение
  онбординга, переход по каждому разделу навигации, сохранение прогресса
  после перезагрузки.
- **CI (GitHub Actions)**: unit- и E2E-тесты, пересъёмка скриншотов README
  на push в main и pull request; деплой на GitHub Pages после push в main.
- Целостность контента: уникальные ID карточек, правильные ответы входят
  в варианты, нет дублирующихся вариантов.
- `manifest.json` — валидный JSON, все пути к иконкам и скриншотам существуют.
